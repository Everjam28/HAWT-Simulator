# HAWT Simulator

Simulador interactivo de una turbina eólica de eje horizontal (HAWT), desarrollado como proyecto académico para la asignatura de Modelación y Simulación.

## Descripción

HAWT Simulator es una aplicación web interactiva que permite visualizar y explorar un modelo tridimensional de una turbina eólica de eje horizontal.

El proyecto busca representar visualmente conceptos relacionados con el funcionamiento y comportamiento dinámico de una turbina eólica mediante una interfaz moderna e interactiva.

## Características

* Visualización 3D de una turbina eólica HAWT.
* Modelo tridimensional interactivo.
* Animación del movimiento de las aspas.
* Interfaz web moderna y responsive.
* Interacción con el modelo mediante controles visuales.
* Desarrollo utilizando React y TypeScript.
* Renderizado 3D mediante Three.js.

## Tecnologías

* React 18
* TypeScript
* Vite
* Three.js
* React Three Fiber
* @react-three/drei

## Requisitos

Antes de ejecutar el proyecto necesitas tener instalado:

* Node.js
* npm

## Instalación

Clona el repositorio:

```bash
git clone https://github.com/Everjam28/HAWT-Simulator.git
```

Ingresa al directorio:

```bash
cd HAWT-Simulator
```

Instala las dependencias:

```bash
npm install
```

## Ejecución

Para iniciar el servidor de desarrollo:

```bash
npm run dev
```

Vite mostrará en la terminal la dirección local donde podrás acceder al simulador.

## Compilación

Para generar la versión de producción:

```bash
npm run build
```

Para visualizar la versión compilada:

```bash
npm run preview
```

## Contexto académico

Proyecto desarrollado para la asignatura de **Modelación y Simulación** del programa de Ingeniería de Sistemas.

El simulador se utiliza como herramienta visual para estudiar y representar el comportamiento de una turbina eólica de eje horizontal (Horizontal Axis Wind Turbine, HAWT).
